# LiftLog Documentation

Working course documents for CEN4090L (Group 9). The app's code lives in the main `LiftLog` folder (see the
main README). Submitted versions of each increment's documents are on Canvas, not in this repository.

| Folder | What goes here |
|---|---|
| `templates/` | Blank official templates from Canvas. Copy these; don't edit them. |
| `requirements-design/` | Software Requirements and Design (RD) document, updated each increment. |
| `requirements-design/diagrams/` | Diagram images and their editable source files (`.drawio` files open free at https://app.diagrams.net). |
| `implementation-testing/` | Implementation and Testing (IT) document, updated each increment. |
| `progress-reports/` | A new progress report for each increment. |

## File naming
- RD and IT documents: `LiftLog_RD_vX.Y.docx`, `LiftLog_IT_vX.Y.docx`
- Working drafts that haven't been submitted add `Draft`, e.g. `LiftLog_RD_Draft_v0.4.docx`
- Progress reports: `Progress_Report_Increment_1.docx`, and so on
